# Heaven's Cake

Official website for **Heaven's Cake** — an FSSAI-registered homemade cake shop in Mannarkkad, Palakkad, Kerala, crafting fresh custom cakes and desserts for every celebration.

## Live Website

- **Primary:** [heavens-cake.web.app](https://heavens-cake.web.app)
- **Mirror:** [heavenscake.vercel.app](https://heavenscake.vercel.app)

## Features

- **Product Catalog & Live Search:** Browse homemade cakes, desserts, and custom hampers with instant search and filtering.
- **Custom Cake Pricing Guide:** Transparent pricing for special designs (Doll, Car, Heart/Square cakes), fondant customization, and ½ kg orders.
- **Customer Reviews & Ratings:** Verified product ratings and customer reviews powered by Firebase Authentication and Cloud Firestore.
- **Direct WhatsApp Ordering:** One-click ordering linked directly to WhatsApp for quick customization and delivery inquiries.

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES Modules), Swiper.js
- **Authentication & Database:** Firebase Authentication & Cloud Firestore
- **Hosting:** Firebase Hosting & Vercel
